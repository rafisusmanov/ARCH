# Работа с Creative Engine из GitHub

Репозиторий: https://github.com/rafisusmanov/architektonica-creative

1. Получить актуальный checkout; перед изменениями проверить ветку, рабочие файлы и свежий main. Не выдавать старые заметки о PR за текущее состояние GitHub.
2. Прочитать [AGENTS.md](AGENTS.md), затем [QUICK_START](QUICK_START.md). Эти документы задают приоритеты, обнаружение навыков, зависимости и команды проверки; отдельной системы правил здесь нет.
3. Выполнять изменения в отдельной ветке, проверить diff, целостность и тесты, подготовить PR с результатами. Не сливать main и не развёртывать production без отдельного поручения.
4. При отсутствии GitHub API/авторизации подготовить локальные изменения и ветку в доступных пределах, явно отметить создание PR и GitHub Actions как NOT RUN. Успешный push не является запуском или успехом CI.

Codex обнаруживает навыки в .agents/skills; поддержка других сред зависит от хоста. Наличие GitHub-коннектора не устанавливает SKILL.md как системные навыки и не обеспечивает фоновую память между запусками. Сохранять весь checkout со связанными источниками; не копировать одну папку без зависимостей.
