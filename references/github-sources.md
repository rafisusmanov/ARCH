# GitHub-источники методов и границы адаптации

Эта запись описывает источники авторских редакционных методик от 18.10.2026: они **изложены и переработаны заново под ARCHITEKTONICA**, а перечисленные ниже паки не установлены. Позднее отдельно включены 9 оригинальных веб-навыков Emil (MIT, `../third_party/emil-skills-LICENSE`) и исполняемый выборочный UI/UX Pro Max (MIT); его состав и локальные изменения — в [документе интеграции](../methods/ui-ux-pro-max-integration.md). Не переносить старое утверждение «сторонних навыков и скриптов нет» на текущий комплект.

- https://github.com/coreyhaines31/marketingskills — вдохновение для `customer-research`, `marketing-psychology`, `copywriting`, `cro`, `offers`, `ai-seo`.
- https://github.com/boraoztunc/skills — `ogilvy`, `stop-slop`, `editorial-portfolio-chapters`, `documentary-brutalist-agency`, `better-writing`. Полные запретительные чеклисты не заимствуются.
- https://github.com/OpenAnalystInc/10x-Content-Expert — `content-analyzer`, `hook-generator`, `brand-voice-manager`, `content-frameworks`, маршрутизация задач.
- https://github.com/WilliamSaysX/skill-forge — упаковка `SKILL.md`, отдельные reference-файлы и принцип загрузки материалов по задаче. Сам мастер-инсталлятор не требуется.
- https://github.com/kostja94/marketing-skills — `entity-seo`, `generative-engine-optimization`, `keyword-research`, `website-structure`, `eeat-signals`. Некоторые навыки страниц перенесены в Pagina; для Architektonica их механически не заимствуем.

Методики маркетинга здесь — редакторские и стратегические инструменты. Их наличие в GitHub не доказывает, что определённый заголовок улучшит конверсию. Для эмпирических выводов опираемся на пользовательский исследовательский реестр, сохраняем номера F/M/ST.
