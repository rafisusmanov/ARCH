## Источники и сборка

- [Утверждённый HTML v9.3](ARCHITEKTONICA-brief-v9.html) — открывать локально в браузере, не размещать на публичном сайте. SHA-256: `660eab5a2197ca0d0f46dc8818de8f6c20805bb86b3f56a802213ed9bac5c543`.
- [Тексты 84 брифов (344 вопроса)](../contact-briefs.tsv) — авторитетный редактируемый UTF-8-источник вопросов. [Каталог](../public-service-catalogue.json) определяет состав, ID, публичные названия и поисковые алиасы услуг.
- [Шаблон](architektonica-brief-template.html) — редактируемый UTF-8-источник интерфейса; [сборщик](build-architektonica-brief.mjs) добавляет поисковые теги и встраивает данные. Не редактировать итоговый HTML вручную.
- [Проверка логики](test-brief-logic.cjs) — Node.js, модель DOM, без сетевых запросов и внешних зависимостей. Не заменяет реальный браузерный QA.

Из корня ARCH выполнить (Node.js 18+):

```sh
node planning/stage-02/contact-prototype/build-architektonica-brief.mjs
node planning/stage-02/contact-prototype/test-brief-logic.cjs
git diff --exit-code -- planning/stage-02/contact-prototype/ARCHITEKTONICA-brief-v9.html
```

Сборка проверяет строгий UTF-8 исходников, отсутствие U+FFFD, состав каталога, число вопросов, дословное совпадение всех 84 `display_title` с лейблами брифов и описание группы «Видео, 3D и интерактивные проекты». Поставляемый HTML содержит только ASCII: Unicode-экранирование JSON/JS и числовые HTML-сущности защищают русский текст от повреждения на границах многобайтовых символов при передаче. Декодированный каталог проверяется на точное совпадение с исходником, включая поисковые алиасы. При новой принятой редакции обновить версию, тесты и контрольную сумму.

## Результат аудита v4–v9

- Поиск по словоформам, синонимам, тегам и свободным фразам; «чат-бот» / «чат с ботом» объединяются. Ранжирование по числу совпавших слов и весу, мягкий порог только при пустой строгой выдаче. Динамическое склонение счётчиков.
- Ссылки на сайты собираются один раз. Уточнения 005, 016, 019, 046, 076, 083, 086 внесены в TSV; все 84 ID сохранены. Нет вопросов о предполагаемом бюджете.
- Выбор нескольких услуг, открытые/закрытые ответы, сохранение текста «Свой вариант» и «Пока не знаю»; скрытые/неактивные ответы исключаются из итогового обращения. Черновик по желанию, без сохранения контактов и вложений.
- Валидация контактов по выбранному каналу; согласие не отмечено заранее и сбрасывается только при изменении контактов. Согласие и политика – отдельные проекты документов, не финальные реквизиты или юридически утверждённые тексты. Имя, контакт и данные проекта применяются только к обращению и связи, без рекламной рассылки.
- Поддержка выборки HEIC/HEIF, PPTX, ZIP, XLS, Pages и других расширений; одноимённые файлы не теряются. Демо хранит только имена. Длины текстовых полей ограничены. SEO description/OG присутствуют, noindex действует до выпуска.
