2. Для следующей страницы сначала read-only проанализировать все существующие блоки WEB, сопоставить IA, [Only UX](../../methods/text-reference-only-digital.md), [WEB/reference](../../methods/web-reference-style-and-depth.md) и подготовить **полный** профессиональный вариант по [контракту](../../methods/stage-02-full-page-contract.md) в чате.
