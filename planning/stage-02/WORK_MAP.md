## Порядок редакционной работы

1. Проверить [AGENTS](../../AGENTS.md), утверждённую IA, Brand Core, Services и соответствующие фактологические источники. Ориентироваться на **две утверждённые страницы** и новый [редакционный стандарт](../../methods/site-voice-and-consistency.md), а не на отозванные варианты.
2. Для следующей страницы подготовить один цельный профессиональный вариант в чате. Самостоятельные исследования должны опираться на реальные данные, источники, методику и результаты.
3. Получить явное утверждение владельца **конкретной редакции**, затем сохранить её в рабочей ветке дословно. Публикация в WEB и слияние PR – отдельные действия.
4. **Решение владельца 10.11.2026:** на главной показывать два отдельных уровня навигации: верхний «Проекты / Услуги / Контакты / Кабинет клиента» и раскрывающееся «Главное / Компания / Проекты / Услуги / Контакты / Блог / Исследования / Карьера / Кабинет клиента». Это единственные изменения утверждённой главной; остальные абзацы сохранены. «Карьера» – название маршрута `/careers`; адрес клиентского кабинета ещё не утверждён, активный вход не показывать. [IA](../stage-01/IA_PROPOSAL.md) обновлена отдельно.
5. Не начинать Stage 03, не объявлять публикацию и не восстанавливать старые сброшенные черновики по умолчанию.

**Очистка служебных материалов:** пустые файлы сброшенных редакционных заготовок `06_Reference_Texts`, `07_Copy_Registry` и `09_Engine_Home_Copy` удалены из активного дерева; их исторические версии остаются в Git. Файл `08_Site_Content_Plan` сохранён, поскольку участвует в проверке целостности пакета. Ни одна утверждённая публикационная страница не удалена.

**Отмена владельца 10.11.2026:** самостоятельная страница «Как мы работаем» (`/process`) исключена из Stage 02 и IA. Из утверждённой главной убрана только ссылка на этот отменённый раздел, другие абзацы не изменены. Предыдущие требования о блоке кабинета именно на `/process` переадресованы на релевантные страницы; отдельный клиентский кабинет сохраняется в редакционной очереди. Следующая новая страница – `/services`.

**История решений:** сброс неутверждённого корпуса 03.11.2026; первоначальная главная 08.11.2026 заменена редакцией, утверждённой 09.11.2026; `/about` и самостоятельный раздел исследований также утверждены в указанном объёме 09.11.2026. Исторические версии доступны в Git.
