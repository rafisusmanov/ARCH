# Creative Engine: независимые испытания A–G

evaluation_only / not_approved / not_for_publication

[Итоговый отчёт](REPORT.md) · [Исходное задание](REQUEST.md)

Материалы содержат неизменённые диагностические ответы моделей. Они не являются утверждёнными текстами Stage 02 и не предназначены для публикации на сайте.

В `runs/<version>-<scenario>-<repeat>/response.md` сохранён полный первоначальный ответ. `input.json` содержит исходный запрос, инструкции запуска, модельные метаданные, SHA и манифест источников; `actions.jsonl` содержит зарегистрированные чтения и обращения к перехватчику. В G последующий ответ хранится отдельно. Исходные ответы не редактировались.

`reviews/` содержит отдельные слепые редакционные оценки, их промпты и журнал загрузки материалов. `evidence/blind-map.json` раскрывает соответствие анонимных кодов исходным прогонам. Редакторские исправления не применялись.

Полные байты загруженных пакетов источников сохранены без потерь в `source-packs/` (gzip + base64 в JSON). Команда `python3 decode_sources.py source-packs/candidate.json candidate-A-1 decoded/` восстанавливает пакет конкретного прогона и дополнительные источники; SHA-256 проверяются при восстановлении.

Точные API model IDs, build revisions, temperature/top_p/seed и полный платформенный trace не предоставлены средой. Это реальная модельная оценка в независимых контекстах, без человеческой приёмки. Охват и ограничения описаны в отчёте.
