# Быстрый запуск

**Для оформления портфолио:** напишите «Я сделал сайт / видео / программу / приложение …». AI должен создать готовую страницу проекта для портфолио, а не сначала собирать бриф. Смотрите `prompts/PORTFOLIO_ONE_MESSAGE.md` и `skills/architektonica-portfolio-case-writer/SKILL.md`.

## В Codex / рабочем checkout

1. Прочитать [AGENTS.md](AGENTS.md) и [утверждённый план v2](references/project/ARCHITEKTONICA_SITE_PLAN_V2.md).
2. Из корня репозитория установить зависимости проверок: `python3 -m pip install -r requirements-dev.txt`. Нужен Python 3.11+; поиск UI/UX использует только стандартную библиотеку. При изоляции окружения разместить venv вне репозитория.
3. Выполнить `python3 scripts/skill_catalog.py` или вариант с `--json`. Выбрать навыки по задаче и [карте применения](methods/engine-template-adaptation.md), прочитать SKILL.md и нужные ресурсы. explicit-only не запускать автоматически.
4. Редактировать источники skills; после изменения выполнять `python3 scripts/sync_skills.py`. Зеркала отличаются только пересчитанными внешними относительными путями. Не редактировать обе копии независимо.
5. Проверить `python3 scripts/verify_package.py` и `python3 -m unittest discover -s tests -v`. CI запускает те же команды. Это целостность Creative Engine, не браузерная проверка сайта.

Команды в этом документе выполняются из корня. Из другого каталога вызывать скрипты по абсолютному пути; они находят собственные ресурсы относительно файла, а не текущего каталога. Сохранение результатов поиска требует явного `--output-dir` и проверки существующих решений.

## В ChatGPT

1. Создайте проект Architektonica (если он уже есть — используйте его).
2. Вставьте `PROJECT_SYSTEM_PROMPT.md` в инструкции проекта.
3. Прикрепите AGENTS.md, [контракт полной страницы](methods/stage-02-full-page-contract.md), [анализ референсов](methods/web-reference-style-and-depth.md), методику маршрутизации и необходимые файлы из `references/project/`, включая полный план v2. До Stage 03 изучать WEB только в режиме чтения; никогда не изменять WEB по поручению написать текст. Для задач с психологией выбора прикрепите исследовательский реестр; для поклеточного заполнения сайта — исходный Excel Engine.
4. Отправьте один из запросов ниже. Число доступных навыков сверяйте с фактическим каталогом; они могут использоваться как справочник без нативной поддержки Agent Skills.

## В Perplexity Spaces

1. Создайте Space Architektonica.
2. Поместите в инструкции содержимое `prompts/PERPLEXITY_SPACE.md`.
3. Добавьте документы из `references/project/` и исследовательский реестр. Если среда ограничивает число файлов, загрузите AGENTS.md, план v2, Fact Bank, Services, Case Studies и Brand Core; остальные подключайте по задаче.
4. Не смешивайте поисковые сведения о рынке с доказательствами собственных результатов компании.

## В Claude Code / иной Agent Skills среде

1. Скопируйте полный checkout, включая `skills/`, `.agents/skills/`, `methods/`, `references/`, `samples/`, `scripts/` и `third_party/` в рабочий проект с сохранением относительных путей.
2. Если хост ожидает другую папку навыков — не перемещайте исходные навыки вслепую: настройте чтение исходного каталога средствами хоста либо подготовьте отдельную копию с пересчитанными ссылками. Готовое зеркало .agents рассчитано только на свою глубину каталогов.
3. Добавьте `PROJECT_SYSTEM_PROMPT.md` в проектную инструкцию агента.
4. Убедитесь, что агент умеет читать `.xlsx`; если нет, предоставьте выводы из `methods/research-evidence-map.md` и экспорт нужных листов текстом.

## Engine и UI/UX — как пользоваться

Engine – понравившийся владельцу визуальный шаблон, который **дорабатываем по дизайну, композиции и пространственной глубине, сохраняя основу и расширяя недостающими смысловыми блоками** под разделы, блог, статьи, услуги, кейсы и тексты компании. Начинать с `methods/engine-template-adaptation.md`, а не с поклеточной таблицы. Для применения UX-исследований использовать `skills/architektonica-ui-ux-expert/SKILL.md`; установленный поисковый инструмент вызывается из корня репозитория командой `python3 third_party/ui-ux-pro-max/scripts/search.py "premium immersive corporate" --design-system -p ARCHITEKTONICA`. Для статьи определять её структуру, для встроенного блог-блока — подходящие превью и переходы.

## Примеры команд

**Следующая страница Stage 02:**
> Подготовь в чате одну лучшую полную редакцию страницы ARCHITEKTONICA по конкретной задаче. Прочитай [утверждённую главную](planning/stage-02/home-page.md) вместе со [страницей «О компании»](planning/stage-02/about-page.md) как эталон прямой, профессиональной, предметной речи без заискивания, «спасательства» и лишней лирики. Сохрани собственную идею и форму страницы, не копируй главную. Проверь факты и требования Stage 01, затем согласуй со мной до записи в GitHub. Уже утверждённую главную не переписывай.

**Страница услуги:**
> Напиши страницу «Брендинг». Покажи, какие решения меняются благодаря айдентике, а не перечисляй логотип, палитру и носители. Если нет публичного кейса этой услуги, не выдумывай его — найди иной способ убедительно объяснить ценность.

**AI-направление:**
> Напиши AI-страницу для R&D-директора: точный терминологический язык, сильная история про решение химика, ясное различение архитектуры, интерфейсного прототипа и предложенной проверки. Объясни, почему это интересно бизнесу, но не объявляй запланированные функции внедрёнными.

**Кейс:**
> Преврати выбранное мной фактическое досье проекта в содержательный кейс. Текст должен быть похож на историю, которую хочется дочитать; роль и итог работы назови предметно, без рекламного жаргона. Нужны заголовок, лид, блоки, финал.

**Критическая редактура:**
> Представь, что текст уже написан. Найди содержательные слабости мысли, предложения и языка, затем представь исправленную версию. Если концепция не работает, замени её целиком. Не вычищай хорошие образы только за то, что это образы.

**Для Excel Engine:**
> Заполни колонку E в копии исходного шаблона Engine по всем полям главной страницы. Не изменяй идентификаторы и остальные колонки. Пропускай фейковые отзывы, цифры и награды; предложи честную замену блоков и сохрани её отдельно.
