# ARCHITEKTONICA — сценарии приёмки сайта

Скоуп: конкретный commit, URL preview, список страниц/локалей, утверждённые референсы. Этот checklist — **контракт тестирования**, не заявление о готовности сайта. Измерения выполняются в WEB. Ссылки на внешние инструменты — справка, установка и права отдельно.

## Визуальное сравнение
- Базовый набор экранов: 1440x900, 768x1024, 390x844, 320 CSS px; точные эталоны утверждает владелец. Снимать ключевые состояния до/после взаимодействий, а не только первый экран.
- Браузерная матрица: Chromium, Firefox, WebKit (Playwright); реальный iOS Safari и Android Chrome. Эмуляция Playwright не подтверждает поведение настоящего телефона.
- Фиксировать одинаковые: build SHA, контент, локаль, viewport, DPR, шрифты, время ожидания, `prefers-reduced-motion`, положение скролла, состояние меню. Разные снимки без детерминизма не годятся в baseline.
- Выход: baseline, actual, diff, путь/номер шага; проверка возможных ложных срабатываний. Никогда не «обновлять эталон, чтобы тест стал зелёным».

## WCAG 2.2 AA — автоматические и ручные процедуры
- Автоматически: axe-core с `wcag2a,wcag2aa,wcag21a,wcag21aa,wcag22aa`, контраст, имена элементов, роли, ARIA, основные ошибки DOM. Набор тегов и покрытие зависит от актуальной версии axe.
- Вручную: полный Tab/Shift+Tab маршрут, Escape и возврат фокуса, отсутствие keyboard trap, фокус виден и не перекрыт sticky-навигацией, раскрытие меню и модалок, полная активация CTA.
- Масштаб: 200% и reflow до 320 CSS px; проверить порядок чтения и смысл без движущихся сцен.
- VoiceOver с Safari, NVDA с Firefox/Chrome: структурные заголовки, landmarks, формы/ошибки, альтернативные подписи, статусы и озвучивание переходов.
- Touch: доступность альтернатив drag, размеры/дистанции целей и отсутствие hover-only контента. Сложные 3D-сцены — статический/DOM-эквивалент фактов, кнопок и маршрутов.
- Reduced motion: ни один ключевой текст/CTA не зависит от scroll/GSAP; пользователь сохраняет контроль над движением. Не создавать ловушки фокуса и неожиданное вращение.

## Проверка пространственных сцен
1. Нормальный scroll вверх/вниз, быстрый скролл, возврат назад, переход по якорю, resize/orientation change и восстановление из bfcache.
2. GSAP timeline/tweens и ScrollTrigger: сброс/cleanup при уходе со страницы, отсутствие повторных инстансов после повторного входа, корректный refresh после загрузки шрифтов и медиа, корректное поведение скрытых вкладок.
3. Lenis: не перехватывать нативный скролл у форм/диалогов, правильно синхронизировать ticker/ScrollTrigger; не оставлять дополнительные RAF loops при re-init.
4. Three.js/WebGL: остановка offscreen, ограничение DPR и ресурсов, освобождение geometry/material/texture/render targets, обработка context lost/restore и fallback. Проверить отсутствие долговременного роста памяти после циклов переходов.
5. Проход без motion/WebGL/JS по проектным правилам progressive enhancement: информация, критическая навигация и CTA доступны.

## Производительность: доказательства
- Раздельно: LCP, INP, CLS по реальному p75 (целевые ориентиры 2.5s/200ms/0.1); лабораторный Lighthouse — диагностический сигнал, не подтверждение полевых p75.
- Для каждой тяжёлой сцены согласовать budget: загрузка (байты/декодирование), LCP, frame-time, long tasks, GPU/CPU, память, максимум текстур и слушателей, влияние на аккумулятор. Числа определять после профиля устройств, а не выдавать как универсальные.
- Проверить два реальных профиля устройств (слабее и сильнее) и низкую сеть. Зафиксировать trace, FPS/просадки, память до/после повторных открытий сцен.
- P0: потеря данных, опасный security дефект, ключевая функция/навигация недоступна. P1: существенная потеря контента, недоступный маршрут, блокирующий keyboard/мобильный дефект, значимая регрессия. P2: локальный стиль/второстепенное неудобство.

## Формат отчёта
`ID | URL + locale | Browser/Device | Build SHA | P0/P1/P2 | Steps | Expected | Actual | Evidence | Owner | Re-test | Status`.

Итог: охват маршрутов и устройств, PASS/FAIL/NOT RUN, блокирующие проблемы, ссылки на скриншоты и traces, явно названные ограничения. **Автоматическая проверка Creative Engine не заменяет этот прогон.**
